CRU Categoria, como uma entidade propria.
cada item tem uma categoria, cada categoria pode ter 0 ou n items
Items> Filter By categoria


```
$rails g scaffold Category name description
# Gerou o CRUD Category

$rails g migration AddCategoryToItems category:references
# Adicionou a coluna categoria na tabela Items, a coluna já faz referencia a tabela Category

Alterei migration AddCategoryToItems para permitir valores nulos, necessário para compatibilidade com o DB atual

$rails db:migrate
# atualizou o db com as migrations geradas

Criei duas categorias: "Supermercado | Casa"

$rails c
# para acessar o console do rails e testar formas de capturar apenas os nomes das categorias já existentes no db
```
